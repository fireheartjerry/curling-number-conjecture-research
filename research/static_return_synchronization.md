# Static return synchronization does not force an aligned root

This note tests a static replacement for the failed actual-state lift.  The
proposal is to keep one raw power equality fixed and repeatedly replace a
return containing an unmatched occurrence by the shorter return exposed by
that occurrence.  Raw return length is then well founded.  The missing point is
that a terminal return in this descent need not begin at a marker boundary.

## 1. What the code and recognizability results supply

Let `F` be a marker and put a boundary immediately after every occurrence of
`F`.  The raw words from one boundary to the next are the first right returns
to `F` in the convention of Valerie Berthe, Clelia De Felice, Francesco
Dolce, Julien Leroy, Dominique Perrin, Christophe Reutenauer and Giuseppina
Rindone, *Maximal bifix decoding*, arXiv:1308.5396, Section 4.1.  That section
defines first right returns and states that they form a prefix code.  Hence a
concatenation which is already known to start at a boundary has a unique
return decomposition.

A stronger fact is available in the recurrent setting.  Fabien Durand and
Samuel Petite, *Conjugacy of unimodular Pisot substitution subshifts to domain
exchanges*, arXiv:1408.2110, Proposition 5(1), state that the return words to a
nonempty prefix of a uniformly recurrent sequence form a circular code.  Their
return convention is the start-to-start, or left-return, convention.  The
right and left return sets are associated by

```
F R_right(F) = R_left(F) F
```

as recorded in *Maximal bifix decoding*, equation (4.1).  A periodic circular
word, read bi-infinitely and rotated so that `F` is a prefix, satisfies the
recurrence hypotheses.

Neither statement moves a boundary backward through an incomplete return.
The code property decodes a word which already begins at a boundary.  The
circular-code property excludes two closed cyclic decompositions of the same
word.  A power factor which begins inside one return and ends at a boundary is
not such a closed alternative decomposition.

Mosse recognizability is also not an applicable upgrade.  Its standard
hypothesis is an aperiodic fixed point or shift generated by a primitive
morphism; see Marie-Pierre Beal, Dominique Perrin and Antonio Restivo,
*Recognizability of morphisms*, arXiv:2110.10267, Introduction.  The return
coding here is only an injective coding morphism for one periodic circular
word.  No primitive substitution having that coding as its substitution is
given.  More importantly, the marker itself already gives forward
recognizability: after the next complete occurrence of `F`, the parse is
synchronized.  The question at issue is retroactive synchronization of the
start of the factor, which recognizability does not assert.

## 2. One primitive circle realizes both terminal defects

Let `F` be any unbordered word whose final letter is `e` and whose first letter
is not `e`.  This includes every complete top marker

```
F=A_h e
```

used in `top_return_straddle.md`.  Put

```
U=F,
V=eF,
C=V U=e F F.                                      (1)
```

Read `C` as a circular word.

### Lemma 1 (exact return set)

The occurrences of `F` in `C^Z` are exactly the two displayed occurrences per
copy of `C`.  Consequently the exact return-token circle is

```
V,U,
```

and its set of return types is `{U,V}`.

### Proof

An occurrence starting at one of the displayed separator letters `e` cannot
equal `F`, because `e` is not the first letter of `F`.  Any other
nondisplayed occurrence overlaps a displayed occurrence of `F` at a shift
strictly between `0` and `|F|`.  The overlap equates a nonempty proper prefix
of `F` with a suffix of the same length.  That is a nonempty proper border of
`F`, contrary to the hypothesis.  The gaps between consecutive terminal
occurrences are the displayed words `eF=V` and `F=U`.

The circle `C` is primitive.  Indeed, a period of `C` permutes the occurrence
set of `F`.  The two cyclic gaps between those occurrences have unequal
lengths `|F|+1` and `|F|`, so a period cannot exchange the two occurrences.
If it fixes either occurrence, it is a multiple of `|C|`.

### Lemma 2 (no-straddle terminal descent)

The raw square

```
U^2=F^2
```

starts immediately after the leading `e` of `V` and ends at the next boundary
after `U`.  Its first copy is the proper suffix `U` of the containing return

```
V=eU,                                             (2)
```

and its second copy is an aligned return.  No marker straddles the first root
start.  Thus the proposed containing-to-suffix retokenization makes the strict
step

```
V -> U.                                          (3)
```

It then stops with the first occurrence of `U` still unaligned.

### Proof

Equation (1) is the literal identity `C=eU^2`.  The first `U` begins one
letter after the boundary before `V`; Lemma 1 shows that the next marker ends
only at the end of this `U`, so there is no straddling marker.  The second
`U` begins at that marker boundary.  The only shorter return type available
from (2) is `U` itself.  Its first occurrence still begins one letter after
the preceding boundary, so reaching the shorter return has not aligned the
root start.

### Lemma 3 (one-letter-straddle terminal descent)

At the boundary before `V`, the preceding `|V|` raw symbols are also `V`:
they consist of the terminal `e` of the preceding return `V`, followed by the
intervening return `U`.  Hence `C^Z` contains the square

```
V^2=(eU)^2
```

whose first root starts at the terminal letter of a marker and whose second
root is the aligned return `V`.  This is the one-letter straddle, and its
containing-to-suffix retokenization is again (3).  It stops at `U`, but now
the occurrence of `U` in the first root is aligned and the occurrences of
`U` inside the later aligned copies of `V` are unaligned.

### Proof

Immediately before the chosen boundary lies the return `U`.  One letter
before that return lies the last letter `e` of the preceding displayed `F`.
From that letter through `U` the word is `eU=V`.  The next return is the
aligned token `V`, proving the square identity.  The boundary before the
intervening `U` is exactly one letter after the first root start, so this is
the one-letter straddle.  Finally, deleting the leading `e` from each copy of
`V` leaves `U` occurrences separated by those leading `e` letters, not a
consecutive power of `U`.  Therefore the original power equality supplies no
further retokenization step.

Lemmas 2 and 3 are a counterexample to the static synchronization claim under
the complete unbordered-marker hypotheses.  Strict return length proves only
that a descent terminates.  It does not prove that its terminal occurrence is
aligned.  The same two-return primitive circle exhibits both defects, so
alternating or merging the two defect rules does not repair the implication.
This is a counterexample to the marker-and-power mechanism alone; `C` is not
asserted to be a curling fixed profile.

## 3. What full alignment would actually give

There is a useful exact conditional statement.  Let a primitive raw circular
word be decomposed into return tokens

```
R=r_0 r_1 ... r_(s-1),
```

and let `theta(r_i)` be the corresponding raw return.  At the boundary before
`r_i`, define

```
w(r_i)=the first raw symbol of theta(r_i).         (4)
```

This is well defined on return identity.  Assume at every selected boundary:

1. the raw proper-circular curling value is `w(r_i)`; and
2. some maximizing raw power is **fully aligned**: every boundary between
   consecutive copies of its root is a return boundary, and each root copy is
   the same concatenation of complete returns.

Then the proper-circular curling value of the token circle `R` at token phase
`i` is exactly

```
pc_R(i)=w(r_i).                                   (5)
```

For the lower bound in (5), decode the fully aligned maximizing raw power.
Unique return factorization makes its equal raw blocks equal token blocks.
Merely knowing that the start of the final root copy is a boundary is not
enough: the earlier copies may still begin inside returns.  For the upper
bound, any proper token power maps under `theta` to a proper raw power at the
same boundary, so its exponent is at most the prescribed raw maximum.

Equation (5) is a **weighted** fixed profile, not yet an ordinary curling
profile.  To turn `R` into an integer sequence whose symbol at phase `i` is
its curling value, one must replace `r_i` by `w(r_i)`.  If two distinct return
types have the same weight, that replacement identifies them and can create
new powers which do not lift to raw token powers.

The exact model in `mixed_weight_counterexample.md` shows that this is a real
logical obstruction.  Its primitive token circle has

```
w(0)=w(1)=2,  w(2)=3,
pc_R(i)=w(r_i)
```

at every phase.  After projecting token identities to their weights, the
first numeric symbol is `2` while the exact proper-circular curling value at
that phase is `4`.  The required A094004 calibration was run immediately
before this computation.  The amended
`check_mixed_weight_counterexample.py` recomputes the full projected profile
and this mismatch.

Therefore even a successful global alignment theorem would yield only a
lower-maximum weighted return profile.  A genuine lower-maximum induction
still requires either injectivity of the return weight map or a separate
theorem proving that every power introduced by a weight collision lifts to a
raw power.
