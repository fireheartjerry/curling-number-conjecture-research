# Minimality and the predecessor rotation

This note is conditional on the standard critical-word reduction.  It
isolates consequences of *minimal seed length* that are not present in a
bare circular fixed profile.

Let `P` be a primitive critical word of length `n`, with `P[0]=2`, whose
high branch reaches `P^3` and is assumed nonterminating.  Thus `P` has
proper circular profile

```
pc_P(j)=P[j]
```

and a maximizing proper witness at every phase `j` can be chosen with
powered span at most

```
n+j-1.                                             (1)
```

The latter is the first-copy fitting condition.  Assume `P` arose from a
nonterminating seed of minimum possible length, so every seed of length
below `n` terminates.

## 1. Deleting the final symbol strictly lowers the curling number

Put

```
a=P[-1],                 T=P[:-1].
```

Every powered suffix of `T` is a proper circular power of `P` at phase
`n-1`.  Fixedness therefore gives

```
cn(T)<=a.                                            (2)
```

Equality is impossible.  If `cn(T)=a`, the first orbit step from the
shorter seed `T` appends its own curling number `a` and reaches `P`.
The assumed nonterminating orbit of `P` would then make `T` a
nonterminating seed of length `n-1`, contradicting minimality.  Hence

```
cn(P[:-1])<P[-1].                                   (3)
```

In the binary critical branch this is the exhaustive split

```
P[-1]=2  =>  cn(P[:-1])=1,
P[-1]=3  =>  cn(P[:-1]) in {1,2}.                  (4)
```

Equivalently, no proper circular witness attaining the phase-`n-1`
value can fit wholly inside the length-`n-1` prefix `T`; every such
witness crosses the distinguished origin.

## 2. Two fitting adjacent rotations contradict minimality

Suppose `P[-1]=2`, and put

```
Q=P[-1]P[:-1],             rot_left(Q)=P.
```

If `Q` also satisfies the critical synchronization equations, its
deleted seed `Q[1:]=P[:-1]` replays two copies of `Q`.  At the first
square-to-cube divergence it appends `2` and reaches

```
(rot_left(Q))^3=P^3.
```

The deleted seed has length `n-1`, so minimality says its orbit
terminates.  Its later state `P^3` must therefore terminate.  But `P^3`
is a state on the assumed nonterminating high orbit of `P`, a
contradiction.

Consequently the predecessor rotation `Q` cannot satisfy critical
synchronization.

## 3. Only one fitting equation can fail after rotation

For `1<=j<n`, phase `j` of `Q` is phase `j-1` of `P`.  A witness supplied
by (1) for `P` has span at most

```
n+(j-1)-1=n+j-2,
```

which is strictly below the permitted bound `n+j-1` for `Q`.  Hence all
positive phases of `Q` fit.  The proper circular profile is invariant
under rotation, so the fitting-witness equivalence leaves exactly one
possible failure: phase zero of `Q`, which is phase `n-1` of `P`.

Because this phase has target value `P[-1]=2`, every proper circular
square attaining its value has powered span greater than `n-1`.  Such a
square crosses the new distinguished origin.

## 4. A final `2` gives an autonomous-one anchor

The word

```
T=P[:-1]
```

has length `n-1`.  A square suffix of `T` would be a proper circular
square at phase `n-1` of `P` with powered span at most `n-1`, contradicting
Section 3 (or directly (3)).  Therefore

```
cn(T)=1.                                           (5)
```

On the other hand, phase zero of the original critical origin has a
fitting square of span at most `n-1`; that square is a suffix of `P`.
The exact profile bounds every suffix power of `P` by two, so

```
cn(P)=cn(T 2)=2.                                  (6)
```

Thus a minimal critical counterexample ending in `2` is forced to have
the exact one-letter maturation

```
cn(P[:-1])=1,             cn(P)=2.                (7)
```

This is stronger than saying that some circular witness crosses an
origin: it identifies the actual finite prefix before the final symbol
as an autonomous curling-one state.

## 5. Exact residual branch

Equations (2)--(4) do not themselves contradict nontermination.  If
`P=X Y^2`, with primitive maximizing square root `Y=Z2`, deletion of the
last symbol leaves

```
T ends in Z 2 Z.
```

There are arbitrarily long words of this form with curling number one.
A closing argument must combine this finite autonomous-one anchor with
the long circular square required at phase `n-1`, or prove that the
marker-copy ancestry generated by the anchor makes the predecessor
rotation fitting after finitely many quotient merges.
