# Conjugacy geometry of a same-rank restart cycle

This note assumes a directed cycle of minimum-endpoint-rank reset words as
in `moving_boundary_context_loss.md`.  It extracts the exact word equation
of the accumulated splice.  The result does not make the splice tape an
autonomous curling orbit.

## 1. Length preservation on every cycle edge

Let the reset words on a cycle be

```
W_0,W_1,...,W_(m-1),W_m=W_0,
```

and let every `W_i` have endpoint rank `R_0`.  On edge `i`, delete
`b_i=j_i+1` symbols after the first high output and append the word

```
Q_i=(k_i)P_i,
```

where `|P_i|=delta_i`.  The minimum-rank tie break gives
`delta_i<=j_i`, hence

```
|Q_i|<=b_i,
|W_(i+1)|<=|W_i|.                                  (1)
```

The lengths return to their starting value around the cycle.  Every
inequality in (1) is therefore equality.  Put

```
N=|W_i|,
B=sum_i b_i=sum_i |Q_i|,
Q=Q_0 Q_1 ... Q_(m-1).
```

Following the shifts through one cycle gives

```
W_0 Q = A W_0,                                    (2)
```

where `A` is the length-`B` prefix deleted from the accumulated tape.
Both sides of (2) have length `N+B`.

## 2. Exact conjugacy solution

The standard solution of the word equation `A W=W Q` with
`|A|=|Q|` gives words `U,V` and an integer `h>=0` such that

```
A=U V,
Q=V U,
W_0=(U V)^h U.                                    (3)
```

For completeness, divide `W_0` into as many full length-`B` prefixes as
possible.  Equation (2) identifies each such prefix with `A`.  Write the
remaining prefix as `U`, so `W_0=A^h U`, with `U` a prefix of `A`; write
`A=UV`.  Substitution in (2) and left cancellation give `Q=VU`.  This
proves (3), including the cases `U` or `V` empty.

In particular, `A` and `Q` are conjugate, and induction in (2) gives

```
A^r W_0=W_0 Q^r                                  (4)
```

for every `r>=0`.

## 3. Interaction with the primitive reset root

Every reset word is a primitive whole power.  Write

```
W_0=Y^k,                 |Y|=p,                 N=kp,
```

with `k>=2` and `Y` primitive.

### Lemma 1 (short-cycle alignment or near-total shift)

If `B<=N`, exactly one of the following holds:

1. `p` divides `B`, and

   ```
   A=Q=Y^(B/p);                                    (5)
   ```

2. with `g=gcd(p,B)`,

   ```
   B>(k-1)p+g.                                     (6)
   ```

### Proof

Equation (3) makes `B` a period of `W_0` whenever `B<=N`.  The word also
has least period `p`.  If

```
N>=p+B-g,
```

Fine--Wilf makes `g` a period of `W_0`.  The complete primitive root `Y`
then has period `g`, so `g=p` and `p` divides `B`.  Because `B<=N`, the
first `B` symbols of the right side of (2) lie in `W_0`; hence
`A=Y^(B/p)`.  This word commutes with `W_0=Y^k`.  Equation (2) and left
cancellation give `Q=A`, proving (5).

If the Fine--Wilf threshold is not met, integer rearrangement gives (6).
The alternatives are disjoint: (6) implies `g<p`.

The first symbol of `Q` is the first actual high output at the cycle,
namely `k`.  Thus the aligned branch (5) additionally forces

```
Y[0]=k.                                            (7)
```

The splice cycle literally emits whole copies of the primitive reset root
in this branch.

### Lemma 2 (over-window shift)

If `B>N`, there is a word `V` of length `B-N` such that

```
A=W_0 V,
Q=V W_0.                                          (8)
```

### Proof

In (3), the block `UV` has length `B>N=|W_0|`.  Therefore `h=0` and
`U=W_0`.  Substitution gives (8).

Hence a cycle whose total boundary advance exceeds its window length emits
one complete copy of the reset word at the end of every splice period.

## 4. Bounded curing context and the remaining transfer gap

Let `M` be the largest positive symbol on the finite splice alphabet.  By
(4), `A^rW_0=W_0Q^r` ends in `Q^r`.  For `r>M`, its curling number is at
least `r`, so that value is absent from the word; after it is appended it
is a unique final symbol, and the next curling number is one.  Thus
`A^rW_0` is terminal for every `r>M`, while `W_0` is bad.

There is consequently a largest integer `r_*` for which `A^(r_*)W_0` is
bad, and

```
0<=r_*<=M,
A^(r_*)W_0       is bad,
A^(r_*+1)W_0     is terminal.                     (9)
```

Scanning the one new copy of `A` in (9) produces an adjacent
reverse-status boundary of the kind normalized in
`reverse_status_reset.md`.  This bounds the curing context to one splice
block; it does not bound the terminal hitting time at that internal
boundary.

The unresolved issue is autonomous transfer.  The letters of `Q` were
generated by separately restarted suffix orbits.  Equations (2)--(9) do
not say that the undeleted orbit from `W_0` appends `Q`.  The calibrated
self-loop `W_0=323232`, `Q=32` realizes the aligned branch (5) while the
undeleted context raises the next prescribed `2` to `3`.  Any cycle
exclusion must use that context divergence, not only the conjugacy word
equation.
